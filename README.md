# DZ Deals AI

واجهة أولية عربية RTL لمساعد التسوق للجزائر، مبنية باستخدام React + Vite + Capacitor.

## الموجود حالياً
- البحث المباشر عن المنتجات عبر صفحات AliExpress وTemu الرسمية.
- إضافة أسماء المنتجات والميزانية إلى قائمة مقارنة مؤقتة.
- فتح تتبع الشحنة عبر 17TRACK.
- واجهة أولية لقسم المساعد الذكي.

## ما لم يتم ربطه بعد
- لا يوجد حالياً استخراج تلقائي للأسعار أو التقييمات أو الكوبونات.
- لا يوجد اتصال API فعّال لمحادثة الذكاء الاصطناعي.
- تتبع الطرود يفتح موقع 17TRACK ولا يستعلم من API داخل التطبيق.
- قائمة المقارنة مؤقتة وليست مزامنة مع قاعدة البيانات.

لن نستخدم scraping غير مصرّح به، ولن نضع مفاتيح API السرية داخل APK. يجب التحقق من شروط كل مزود وحدود خطته المجانية قبل تفعيل التكامل.

## تشغيل محلياً
```bash
npm install
npm run dev
```

## بناء APK
يبدأ GitHub Actions تلقائياً عند كل push إلى main، ويمكن تشغيله يدوياً من تبويب Actions. بعد نجاح البناء، نزّل ملف APK من Artifacts في صفحة التشغيل. هذا إصدار Debug تجريبي وغير موقّع للنشر على Google Play.
